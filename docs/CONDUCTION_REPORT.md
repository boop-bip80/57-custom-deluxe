## What the numbers say

* **Idle:** each valve draws 38.8 / 38.8 mA plate current (+ 3.8 / 3.8 mA screen) at 21.3 V cathode bias and 388 V B+1; plate dissipation 14.1 / 14.1 W per valve at idle, screen 1.17 / 1.17 W (the shared 250 ohm cathode resistor sets the bias, so it moves with the signal). For scale, the JJ 6V6S sheet in the dossier (Fig. 11) draws its maximum-dissipation hyperbola at 14 W, so the model idles at the sheet's own rating: a hot-biased 5E3-style stage, which is what the published circuit does with these values.
* **At the rated-power point** (largest drive with THD <= 5 %, 11.96 W): conduction angle 333° / 314° of 360°, both valves on for 80 % of the cycle, peak plate current 107 / 108 mA, cathode bias moved from 21.3 V to 23.1 V, B+1 sagged from 388 V to 382 V.
* **At the heaviest drive** (16.7 W, 46.4 % THD): angle 150° / 214°, grid current peaks 67 / 3 uA conducting 39 % / 0 % of the cycle (the blocking-distortion path of Sec. 10), screen current peaks 30 mA, cathode bias 26.8 V.
* The model's valves are therefore neither fixed in class A nor in class B across level: the conduction angle and the overlap change continuously with drive, and the cathode bias and rails move with the average current. No class label is used anywhere in the model; the label is only a way of reading this table.
* The two valves are identical in the nominal model (no specimen mismatch: Sec. 07/10 say to measure it), so the small differences between V3 and V4 columns come from the asymmetric phase-inverter drive, not from the valves.
